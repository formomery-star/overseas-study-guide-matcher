# Publication scope and exclusions

Authorized public scope: source code, generic technical documentation, and synthetic test data only.

Included here:
- Flask intake application and its static form/admin interface.
- Core report/matching source modules, without the production catalog.
- Synthetic JSON fixtures used only for manifest/hash tests.
- Generic run/test notes in this README.

Explicitly excluded:
- Production `database/` records and source evidence (not cleared for redistribution).
- Student questionnaires, source documents, standard profiles, PDFs, HTML/MD reports, attachments, exports, and inbox/runtime data.
- Internal review logs, delivery records, task status, execution records, and private working notes.
- `.env`, keys, passwords, tokens, server data, backups, or cloud credentials.
- Template files containing or derived from identifiable student material.

This candidate is not an exact copy of the working package. Before publication, rerun the privacy/secret scan, inspect the final diff, select a license, and publish only this candidate directory.
